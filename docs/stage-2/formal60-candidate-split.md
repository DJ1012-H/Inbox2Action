## Freeze boundary

The holdout IDs are recorded in `evaluation/holdout-v3.json`. They must not be used for prompt or code tuning before candidate freeze. This asset creation did not call a live model and did not use holdout results.

The 60 policy records are stored independently in `evaluation/policies-v3.jsonl`; they authorize the reviewed action DAG and are not generated by the formal runner from Gold Labels.

The new review records are offline candidate review records. A human must inspect and approve the candidate freeze before any real model call.
